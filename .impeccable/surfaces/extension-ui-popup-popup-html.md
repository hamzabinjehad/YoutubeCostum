## Direction contract

THESIS: A viewing control center answers “what can I improve right now?” before it exposes the full settings catalogue.

OWN-WORLD: Preserve the restrained, platform-native system and semantic state colors; replace the directory-like root hierarchy, not the product’s utility-first character.

STORY: On a YouTube tab, a viewer sees health, active mode, the few actions relevant to this page, and a reversible summary of changes. Expert configuration remains one intentional step away.

FIRST VIEWPORT: At popup size, a compact status bar leads into the active mode, default playback speed, persistent page preferences, a summary of changes, and one explicit Customize route. Current-video actions live in the in-page Now Playing remote. The popup does not claim that persistent preferences affect only the current video.

FORM: Direct local-extension redesign in Operate mode; no concept seed is used because this is an existing extension surface.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
